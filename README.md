## 🎯 **Assignment Overview**

Built as a technical assessment showcasing advanced React state management and UI component integration. The project demonstrates handling complex table interactions with persistent data across component re-renders.

## ✨ **Key Features Implemented**

### **🔢 Dynamic Row Selection**
- **Input-driven Selection**: Enter any number (n) to automatically select first n rows
- **Real-time Updates**: Selection updates immediately on input change
- **Validation Logic**: Handles edge cases and invalid inputs gracefully

### **📄 Pagination with Persistence** 
- **Stateful Navigation**: Navigate between pages without losing selections
- **Cross-page Memory**: Selected rows remain selected when returning to previous pages
- **API Integration**: Fetches new data while maintaining selection state

### **⚡ Performance Optimizations**
- **Persistent State Management**: Maintains selection across component re-renders
- **Efficient Re-rendering**: Optimized state updates to prevent unnecessary renders
- **Memory Management**: Tracks selections across multiple data sets

## 🛠️ **Technical Implementation**

### **Core Technologies**
- **React 18** with functional components and hooks
- **TypeScript** for type safety and better development experience
- **PrimeReact DataTable** for advanced table functionality
- **Custom State Management** for cross-page persistence


### **Key Challenges Solved**
- **State Persistence**: Maintaining selections when API fetches trigger re-renders
- **Cross-page Selection**: Tracking selected items across different data pages
- **Dynamic Input Handling**: Converting user input to programmatic row selection
- **Performance**: Efficient updates without unnecessary component re-renders
